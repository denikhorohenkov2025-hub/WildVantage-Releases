# WildVantage

**WildVantage** — погодное приложение для Android. Показывает текущую погоду и прогноз по данным
сервиса **MET Norway**, определяет ваше местоположение по GPS и позволяет сохранять любимые города.
Данные кэшируются, поэтому последний прогноз можно посмотреть и без интернета.

Здесь выкладываются только установочные файлы приложения (APK). Исходный код в этом репозитории
не публикуется.

## Возможности

- Погода по данным MET Norway: текущие условия и прогноз.
- GPS с показом точности определения.
- Поиск городов на русском языке.
- Избранные города.
- Прогноз на 24 часа.
- Прогноз на 7 дней.
- Метеоиндекс.
- Скорость ветра в м/с и км/ч.
- Уведомления о важных изменениях погоды.
- Фоновое обновление примерно каждые 15 минут.
- Кэш для просмотра данных без интернета.

## Системные требования

- **Android 5.0 (API 21) и новее.**
- **Интернет** — для загрузки и обновления прогноза. Для просмотра ранее загруженного прогноза
  интернет не нужен (см. [Просмотр без интернета](#просмотр-без-интернета)).
- **Геолокация (GPS)** — по желанию. Нужна, чтобы показать погоду для вашего текущего места.
- **Уведомления** — по желанию. На Android 13 и новее для них потребуется отдельное разрешение,
  и только если вы сами включите уведомления.

## Скачивание и установка

1. Откройте раздел **Releases** этого репозитория.
2. В последнем релизе скачайте файл **`WILDVANTAGE-v13.0.9.apk`**.
3. Откройте скачанный файл. Android попросит разрешить установку из неизвестных источников —
   разрешите её для приложения, из которого вы открываете файл (браузер или файловый менеджер).
4. Подтвердите установку.

Если система предупреждает, что приложение из неизвестного источника — это ожидаемо для APK,
которые устанавливаются не из Google Play.

## Разрешение на геолокацию

Чтобы посмотреть погоду для места, где вы находитесь:

1. Нажмите кнопку определения местоположения (GPS) на главном экране.
2. При первом обращении Android покажет системный запрос — выберите **«Разрешить»**.
3. Приложение определит координаты и загрузит прогноз для этой точки.

Если доступ был отклонён, приложение сообщит, что местоположение недоступно. Разрешение можно
выдать позже в системных настройках Android: **Настройки → Приложения → WildVantage → Разрешения →
Местоположение**.

## Поиск городов на русском

1. Откройте строку поиска.
2. Введите название города по-русски, например **«Москва»** или **«Ярославль»**.
3. Выберите нужный город из списка результатов.
4. Приложение загрузит прогноз для выбранного города.

---

## Избранные города

- Чтобы добавить город в избранное, нажмите значок звезды рядом с найденным городом.
- Избранные города хранятся на устройстве и доступны на экране **«Управление городами»**.
- На этом экране город можно выбрать (открыть его прогноз) или удалить из избранного.
- Первой в списке всегда идёт карточка текущего местоположения по GPS. Её нельзя удалить —
  она показывает погоду для точки, где вы находитесь.

## Прогноз на 24 часа и 7 дней

- **Прогноз на 24 часа** — почасовая лента: температура, погода и ветер по часам вперёд.
- **Прогноз на 7 дней** — по дням: минимальная и максимальная температура, погода и ветер
  на каждый день.

Время в прогнозе учитывается для часового пояса выбранного места.

## Метеоиндекс

Метеоиндекс — это ориентировочная оценка того, насколько погода «нагружает» организм (перепады
давления, резкие скачки температуры, жара или мороз, влажность, сильный ветер). Это не медицинский
прогноз и не диагноз — только подсказка, основанная на данных прогноза MET Norway.

Шкала от 0 до 100:

| Значение | Уровень     |
|----------|-------------|
| 0–30     | Низкий      |
| 31–60    | Умеренный   |
| 61–100   | Высокий     |

Чем выше значение, тем больше факторов может влиять на самочувствие. Если данных для расчёта
недостаточно, приложение честно показывает «недостаточно данных», а не выдумывает число.

## Погодные уведомления

1. Прокрутите главный экран до карточки **«ПОГОДНЫЕ УВЕДОМЛЕНИЯ»**.
2. Включите переключатель **«Включить уведомления»** — это общий выключатель.
3. На Android 13 и новее система запросит разрешение на уведомления — разрешите.
4. Ниже можно отдельно включать и выключать категории: дождь, снегопад, гроза, сильный ветер,
   температура, давление.
5. При необходимости включите **тихий режим** — ночью (с 23:00 до 07:00) не будут приходить
   некритичные уведомления.

Как это работает:

- Уведомления приходят при появлении важных изменений: дождь/снег/гроза, сильный ветер,
  резкое изменение температуры, резкий перепад давления.
- Формулировки осторожные: приложение не обещает точное время начала дождя или снега —
  сообщается, что явление возможно в ближайшие часы.
- Один и тот же тип уведомления не повторяется чаще, чем раз в 3 часа.

## Фоновое обновление

- Приложение обновляет прогноз в фоне примерно **каждые 15 минут**, пока задача работает.
- Обновление выполняется системным планировщиком Android и может приходить и при закрытом
  приложении.
- Точный интервал не гарантируется: система (режим энергосбережения / Doze) может откладывать
  обновления до ближайшего «окна активности». Это штатное поведение Android, а не ошибка.
- Для фонового обновления нужен доступ к интернету.

---

## Просмотр без интернета

- Каждый успешно загруженный прогноз сохраняется в кэш на устройстве.
- Без интернета приложение показывает последний сохранённый прогноз.
- Координаты и сохранённые (избранные) города также доступны офлайн.
- Когда интернет вернётся, прогноз обновится автоматически при следующем обращении или
  фоновом обновлении.

---

Если приложение не обновило прогноз, проверьте доступ к интернету и выданные разрешения,
а затем откройте главный экран ещё раз.
